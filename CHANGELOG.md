# Changelog

## 2 - Final release
- Snip shortcut: Alt+Shift+S
- Copy, paste, cut, right-click and text selection work again on blocked websites and online code editors
- Snip to copy (Alt+Shift+S): exact copy of real page text; OCR for pictures, canvas and video in English and Tamil, detected automatically
- Text-reading files are included: nothing to download or set up
- Auto-scroll while selecting long text
- Careful English spell-check for OCR results; reads past the edges of a tight box
- Loading animations: typing dots while reading, spinner while the popup opens
- Works with the normal system clipboard between websites, windows and other apps
- No data collected, no network requests
